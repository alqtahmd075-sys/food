# ⭐ مطعم النجوم — STARS RESTAURANT

موقع مطعم مأكولات بحرية فاخر: **10 صفحات** (عربي RTL) + **باك إند Express** + قاعدة بيانات SQLite/libSQL + لوحة تحكم أدمن + سلة وطلبات وتتبع + حجز طاولات + عروض + تقييمات.

## 🚀 التشغيل على جهازك
المطلوب: **Node.js 18 أو أحدث** (يفضّل 22 LTS).

```bash
npm install
npm run images     # مرة واحدة: بيحمّل كل الصور جوه المشروع (assets/img)
npm start
# افتح: http://localhost:3003
```

قاعدة البيانات `stars_database.db` بتتولد تلقائياً (منيو + صواني + عروض + تقييمات + طلبات تجريبية).
لو مش عايز الطلبات التجريبية: شغّل بـ `SEED_DEMO_ORDERS=false`.

## 🖼️ الصور
كل الصور بتتخزّن جوه المشروع في `assets/img/` ومش بتعتمد على أي سيرفر خارجي، والأيقونات (Font Awesome) كمان محلية في `assets/vendor/`.
1. شغّل `npm run images` مرة واحدة (محتاج إنترنت).
2. اتأكد إن فولدر `assets/img` فيه الصور، وارفعه على GitHub مع باقي الملفات.

الصور المرفقة جاهزة جوه `assets/img/` (صينية الوحش وصينية التنين + صور الأطباق المطابقة). الصور اللي لسه ناقصة بتتحط في نفس الفولدر باسم `<id>.jpg` (الـ id في `scripts/images-list.json`).

لو صورة ناقصة، الموقع بيعرض صورة بديلة بدل صورة مكسورة. لتغيير صورة طبق: حط ملف باسم الـ id بتاعها في `assets/img/` أو حط رابط/مسار الصورة من لوحة الأدمن.

## 👑 الأدمن
الدخول من `/admin`. بيانات الأدمن مش مكتوبة في الموقع. الإيميل الافتراضي `admin@stars.com`، والباسورد متخزّن مشفّر في الكود.
لتحديد بيانات تانية قبل أول تشغيل على قاعدة جديدة: `ADMIN_EMAIL` و `ADMIN_PASSWORD` (راجع `.env.example`).

## 💾 قاعدة بيانات دائمة (Turso) — مهم على الاستضافة
على الاستضافة المجانية (Render) ملف SQLite بيتمسح مع كل إعادة تشغيل، فالطلبات والحجوزات بتضيع. الحل: قاعدة **Turso** (فيه خطة مجانية — راجع turso.tech):
1. سجّل في turso.tech (بحساب GitHub) وأنشئ قاعدة بيانات جديدة.
2. انسخ **Database URL** (بيبدأ بـ `libsql://`) وأنشئ **Token** للقاعدة.
3. في Render → الخدمة → **Environment** أضف:
   - `TURSO_DATABASE_URL` = الرابط
   - `TURSO_AUTH_TOKEN` = التوكن
4. احفظ وانتظر إعادة النشر. في السجل (Logs) هتلاقي: `قاعدة البيانات: Turso (دائمة)`، وفي `/api/health` هتلاقي `"persistent": true`.

## 🌐 النشر على Render
1. ارفع المشروع على GitHub (**Public** أو Private).
2. render.com → **New + → Web Service** → اختار الريبو → Plan **Free** → **Create** (ملف `render.yaml` جاهز).
3. أضف متغيرات Turso من الخطوة السابقة.

### ⏱️ تجنّب بطء أول زيارة
الخطة المجانية بتنيّم السيرفر بعد 15 دقيقة بدون زوار. للحفاظ عليه صاحي: سجّل في **UptimeRobot** (مجاني) وأضف Monitor من نوع HTTP على `https://اسم-موقعك.onrender.com/api/health` كل 5 دقايق.

## 💳 طرق الدفع
- **فودافون كاش:** تبويب فيه رقم العملية والرقم المحوّل منه وصورة الإثبات (اختياري)، وبتتبعت مع الطلب على الإيميل وبتتسجّل في ملاحظات الطلب.
- **فيزا / ماستركارد:** بيتم التحقق من الرقم (Luhn) والانتهاء وCVV على جهاز العميل. **رقم الكارت وCVV ما بيتخزنوش ولا بيتبعتوا** — بيتبعت بس نوع الكارت وآخر 4 أرقام، والدفع بيتم عند الاستلام بماكينة POS. للدفع الأونلاين الحقيقي لازم بوابة دفع (Paymob / Fawry).
- **دفع عند الاستلام:** تأكيد مباشر.
